\subsection{Functional correctness and coverage}

The case rate is conditional on actual evaluation and must be read together with coverage. Each condition plans 81 cases. The current automatic adapter is eligible for 52 of them, and generation/compilation failures can further reduce execution coverage. All remaining cases have fixed manual procedures but cannot be counted as passes without actual trace acquisition. The scalar simulator tests exercise the exact final compiled source; they do not substitute the Python reference implementation.

\subsection{Resources and reliability}

Request-file counts measure attempted calls consistently across frameworks. Reported input/output totals remain incomplete whenever a request has no usage record; they are not estimates for missing calls.
