\subsection{Threats to Validity}
Three methodological boundaries frame interpretation of the empirical findings:
\begin{enumerate}
  \item \textbf{Physical Timer Scale and Host Scheduling Jitter}: Several public timer benchmarks specify cumulative holds spanning minutes or hundreds of hours (e.g., \code{PUB004.T3/T5}), which cannot run in real wall time within fixed campaign budgets. Conversely, sub-second step intervals executed under Windows host 1\,ms task scheduling exhibit microsecond-to-millisecond jitter that can trigger strict tolerance exclusions (\pathcode{TIMING_NOT_REPRODUCED}). Reporting separates these excluded timed cases transparently alongside planned denominators rather than introducing unverified synthetic time-scaling factors.
  \item \textbf{Numeric Semantics Between Real Hardware Types and Exact SMT}: For floating-point tasks such as \code{PUB003}, \code{nuXmv}/\code{MathSAT} models \code{REAL} values over exact rationals rather than IEEE-754 single-precision rounding and overflow. In practice, real CODESYS simulation validates byte-exact \code{binary32} outputs, turning the two stages into complementary runtime and symbolic checks.
  \item \textbf{Symbolic Coverage Frontier and Version Cutoff}: Dynamic \code{VARIANT} bindings, computed string byte slices, and unmodeled arithmetic idioms remain outside the current \code{ST->SMV} lowering fragment and map cleanly to \code{UNSUPPORTED_ST} (8--12 tasks across \textbf{E1}--\textbf{E4}). Additionally, commit \pathcode{cef1388} (decoupled \pathcode{compiler_lock_timeout = 960s} and expanded SMV expression lowering) landed after the 14~November~2026 campaign cutoff; this report preserves all original \code{TOOL_ERROR} and \code{TIMEOUT} classifications verbatim without post-hoc relabeling.
\end{enumerate}

\section{Conclusion and Future Work}

\subsection{Summary of Contributions}
Targeting automated IEC~61131-3 ST synthesis on \code{CODESYS V3.5 SP22 Patch 4}, this project delivers an integrated engineering suite combining: (1)~a normalized 32-task, 276-case, 294-LTL end-of-scan benchmark preserving 20 verbatim public prompts alongside 12 AI-generated, human-reviewed self-built controllers, backed by positive/negative dual-control verification (32/32 reference \code{TRUE}; 32/32 mutant \code{COUNTEREXAMPLE}); (2)~the leak-free \textbf{STAR} multi-stage agent framework uniting structured scan planning, selective dialect cards, hash-guarded compiler repair, assertion-isolated in-loop \code{ST->SMV} CEGAR verification, and anti-lazy lexicographic ratchet selection; and (3)~a symmetric \code{Codex CLI v0.142.5 + MCP} baseline harness alongside offline \code{ScanContract} verification, six-category \code{symbol_glossary.py} auditing, and a zero-dependency interactive WebUI.

Completing the full $2 \times 2$ crossed 128-run benchmark (\textbf{E1}--\textbf{E4}) under maximum reasoning effort reveals crisp architecture--model interactions. For \code{deepseek-v4.1-flash-1017}, \textbf{STAR} raises compilation from \textbf{87.5\% to 100.0\%}, expands evaluated fixed-case coverage from \textbf{196 to 226}, eliminates all \code{SA0027} collisions, and cuts input context \textbf{11$\times$}. For \code{gpt-6.1-terra}, unconstrained \code{Codex CLI} reaches \textbf{99.1\% (220/222)} evaluated case accuracy at lower reported cost (\textyen 5.21 vs.\ \textyen 7.38), whereas \textbf{STAR} adds output-token overhead without functional gain once compilation succeeds cleanly. Meanwhile, concrete counterexamples hidden behind 100\% passing simulation suites on both \textbf{E3}/\code{PUB011} and \textbf{E1}/\code{PUB020} confirm the indispensable value of independent symbolic model checking.

\subsection{Immediate Next Steps}
\begin{enumerate}
  \item \textbf{Post-\pathcode{cef1388} Validation Rerun, Paired Statistics, and Module Ablations}: Re-evaluate lock-contended tasks under the decoupled 960\,s mutex budget and enhanced expression lowering (reported in a separate post-cutoff table), apply exact McNemar paired tests and 95\% bootstrap CIs across all 128 runs, run \code{no_planner}, \code{no_dialect}, and \code{no_selftest} ablations, and prototype complexity-gated routing to avoid multi-role output tax on straightforward tasks.
  \item \textbf{Expand Symbolic Coverage and Multi-Vendor PLC Scope}: Extend \code{ST->SMV} support toward integer modulo and bounded array/string slicing idioms, and generalize the decoupled compiler and simulation backend contract toward additional multi-vendor PLC toolchains such as Siemens TIA Portal.
\end{enumerate}
