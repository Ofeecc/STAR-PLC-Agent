## 总结论（五层问题定位）

当前仓库的核心问题**并非只存在于模型侧，也非全部出在规约上**，而是分布在以下五个层面，且彼此存在传导关系：

1. **评估流水线与规范化规约断链（架构级高危）**：`src/plc_agent/normalized_spec.py` 已实现 `NormalizedScanMonitor`、`check_initial`、`exact_shape_equal` 与 `PUB017` 删除槽回溯，但**从未接入主评测入口 `src/plc_agent/functional.py`**；同时 `baseline.py` 与 `harness.py` 工具透传不对称、`functional.py` 对 `dt_tolerance_ms: 0` 强制改回 `±25 ms`、`metrics.py` 把 `"SAT"`/`"UNSAT"`/`"VERIFIED"` 计作验证通过、`dataset.py` 未真正校验 `module_sha256`、`simulation.py` 把 `PUB008` 非 `1` 数组下界硬编码为 `1` 且缺少 `PUB017` `recipe` `IN_OUT` 追踪。
2. **部分题目存在“原题 / JSON 文本 / LTL 公式 / Python 参考实现 / 测试数据”内部矛盾（P1 级）**：典型集中在 `PUB003`（精确算术 vs `real32`）、`PUB008`/`PUB009`/`PUB020`（容差配置冲突与 `float32` 1 ULP 精度不足）、`PUB010`（首拍 `dt_ms` 累加与故障期更新 `demand`）、`PUB016`（`sequenceIndex=1` vs `index=0`）、`PUB017`（`recipeID<=0`、并发优先级、删后非 ID 字段保留与检查器盲拷贝）、`PUB017`/`PUB018`/`PUB019`（未声明的静默并发优先级）、`SELF012`（混用 `Spre` 与 `O[k-1]`）、`SELF005`/`SELF011`/`SELF012`（`initial_observed` 为空或漏键）。
3. **独立 `P1..Pn`（不含 `CompleteBehaviorV2`）与独立 SMV 性质普遍欠约束，且部分 `Tests` 存在明显漏测**：即使 32 题在全输出强监控语义 `CompleteBehaviorV2` 兜底下总体可用，去掉 `CompleteBehaviorV2` 后，半数以上题目（尤其 `PUB001`、`PUB010`、`PUB011`、`PUB015`–`PUB020`、`SELF004`、`SELF005`、`SELF010`、`SELF011`、`SELF012`）允许退化或错误实现全部通过 `P1..Pn`；队友人工审阅在偶数题复现 **9 项漏测**、在奇数题指出 **10 道公开题 + 6 道自建题** 的正常操作保持与完整周期覆盖缺口（`tests` 中还有 4 题 102 拍共省略 164 项字段断言）。
4. **SMV 模型层存在“实现 Bug + 性质弱化/空真 + Mutant 篡改规约”**：问题集中于 `PUB002_mutant.smv`（修改被检 `P4` 公式且耦合隐藏缺陷）、`PUB014_reference.smv`（漏 `& end_16` NUL 检查与 16B 截断）、`PUB019_reference.smv`（`!safe` 时清空模式记忆与 `ProcessContract` 冲突）、`PUB020_reference.smv`（`P9` 错用 `nextPhase` 致正常周期空真、`P8_safety` 未限路线与禁止入烧成）、`PUB006_reference.smv`（`INVAR` 写入结果事件反向约束环境并致 `V2_bounds` 循环）、`PUB005_mutant.smv`（`startup` 绑定被污染时钟致 `P1` 失敏）、`PUB004`/`005`/`006`/`010`/`013` 的 `coarse_tick` 弱化、`PUB007`/`008`/`013` 的重言式检查，以及 `SELF004`/`005`/`010`/`012` 的 `V2_*` 性质集漏项。
5. **5 类原题边界须先人工拍板**：`PUB004`/`PUB012` 的 `CycleTime` vs `dt_ms` 与时间归属、`PUB010` 的 `>=5s` vs `>5s` 及故障期 `demand`、`PUB014` 的 `STRING(254)` vs 15 字符前导零、`PUB015` 的 D 阀关断与续批、`PUB017` 的负 ID 与并发优先级（以及 `PUB008` `REAL` 只读容差、`PUB019` 急停切模式恢复）。
