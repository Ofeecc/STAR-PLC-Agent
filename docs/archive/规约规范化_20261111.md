# 2026-11-11 规约规范化与逐题定义

本轮针对32题进行规范化，版本为 `2.1-normalized-20261111`。老师原始 requirements、接口、测试输入/预期、原始 initial_conditions 和 assumptions 保持不变。修改的是组内规约的定义、表达和审核材料；本轮不重新计入任何 Agent 成绩。

## 三类问题的处理

1. `CompleteBehaviorV2` 的待办说明全部替换为确定的扫描关系。数学定义为 `(Sref[k+1], E[k]) = T(I[k], Sref[k], dt[k])`，逐项检查独立取得的 `O[k]` 是否满足比较关系。T的精确定义来自固定源码快照和构造初值，函数引用及SHA256写入每题JSON；下方给出中文规则。
2. PUB002将DWORD历史传递展开为32条布尔位等价式，X只作用于布尔命题；PUB009布尔历史使用 `G(trigger <-> X(previousTrigger))`。PUB007量化完全展开为五项合取；PUB008采用有明确序号范围、空合取TRUE、绑定时替换规则的有限合取谓词，辅助函数可生成实例。
3. 每题声明I（扫描前输入）、O（扫描后实际输出）、Sref（独立参考状态）及初值、更新时机、前值绑定。接口输出符号均改为实际O，绝不以期望方程定义实际值。辅助参考状态从固定构造状态出发，每拍只由输入推进；前拍实际输出另存在观察器中。

另外，5条基于物理定时器的活性性质加入 `G(F(TimeTick))` 前提。TimeTick表示跨越新的整数毫秒边界，排除无限调用却时间有上界的Zeno轨迹。仅写“时间前进”或dt>0不足以保证延时最终到期。

## 数值、初始化与表示范围

- 整数和BOOL按类型和值精确比较；有限浮点结果绝对容差1e-5。PUB008只有成功转换的outputValue额外允许相对容差2e-6，保持字段、配置与状态精确比较。时间统一为整数纳秒。
- 初始化观察发生在第一次调用之前；O[0]是第一次执行后的输出，二者不能替代。初值谓词仅约束 `initial_observed` 列出的实际输出字段；其他实际初值未被该谓词约束。独立参考构造状态另有完整序列化定义。
- PUB017包含对实际recipe数据库的比较；成功删除槽的非ID字段当拍不约束，后续不写时与采样实际表示比较保持。允许字段的表示保持检查不改变参考数据库的逻辑状态。
- PUB018不强制候选内部head/tail或环形布局；只约束实际count/status/item和完整输入历史的FIFO行为。绑定A容量2、B容量3，其他绑定容量来自存储元数据。
- 输入类型、任务假设及转移中明确的数值/时间域共同界定评测域。非法域或参考执行异常不能当候选PASS/FAIL。长期公平性前提不能由有限用例证明。

### SELF011 Single cycle actuator handshakes with one transition per scan

mode初值IDLE。Stop或Reset优先回IDLE；IDLE且Start & RetractDone进EXTEND；EXTEND/CLAMP/RELEASE/RETRACT仅各自匹配完成信号推进一阶；DONE保持。四动作输出分别等价于转移后对应阶段，Busy等价于阶段1..4，Done等价于阶段5。

受约束实际字段：Busy, Clamp, Done, Extend, Release, Retract。

### SELF012 Bounded automatic fault retries with a recovery dwell
