# 全题库双语审核界面

中文入口：<http://127.0.0.1:8765/?scope=all&lang=zh>。课堂英文入口：<http://127.0.0.1:8765/?scope=all&lang=en>。右上角即时切换并记住语言，切换不清ST编辑内容、题号或筛选条件；`scope=pilot`可回原六题。

覆盖32题（20公开、12自建）、244条规约、99个固定用例、669步。中文资料延续六题结构：题意、补充约定、完整行为、测试覆盖、重点审核建议，补齐接口中文注释、每条规约含义与用例标签。固定用例可展开逐步输入、dt_ms及预期输出。

支持题号/中英文题名搜索、来源和难度筛选。公开题标为老师提供，自建题不标为老师原题。翻译、补充约定、规约和预期值为组内整理，全部待人工审核；数量不代表覆盖百分比，预期值不是实测证据。

英文模式切换导航、按钮、筛选、表头、指导、题名、规约解释及测试场景。变量名、类型、公式和数据保留原样；原始元数据可展开，其中历史中文补充规约按原文保留。诊断日志保留编译器原文。

展示资料位于 `configs/task_review_zh.json`，由 `scripts/build_chinese_review.py` 的人工整理内容生成。原六题在 `configs/pilot_review.json` 保留。展示资料不加入Agent输入，不改原题、公式或预期值。每题绑定题目哈希，每条规约保存原公式；题目变化时停用旧译文并提示重新审核。

界面维护文件：`src/plc_agent/webui_assets/index.html`、`app.js`；Python API在 `src/plc_agent/webui.py`。资源本地加载，无外部CDN。

审核时先找原题依据，再确认边沿/电平、同拍优先级、初值、计时起点、错误时保持等补充约定；逐条对应公式与谓词，手算正反轨迹，并确认用例实际触发每个前提。尚未接通模型检查的题目不能因显示LTL而标为形式验证通过。
