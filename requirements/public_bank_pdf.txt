     Difficulty: Easy (easy)

Requirements

parameters exceed the normal range, the system needs to issue an alarm. To avoid frequent
triggering of alarms due to minor fluctuations in parameters, an alarm management system with
hysteresis function needs to be implemented.
When Value is greater than hiLevel, trigger high alarm hiAlarm.
When Value is less than hiLevel-hystWindow, exit high alarm hiAlarm.
When Value is less than loLevel, trigger low alarm loAlarm.
When Value is greater than loLevel+hystWindow, exit low alarm loAlarm.
If loLevel is greater than or equal to hiLevel, output error error=true, status=16#8001, and exit the
program
If the hysteresis window value hystWindow is greater than or equal to the deviation range
between hiLevel and loLevel, output error error=true, status=16#8002

  6. If measuringMode is not 0, 1 or 2, set that channel's retVal to 16#8001 and skip its

  7. If hiLIM is less than or equal to loLIM, set that channel's retVal to 16#8002 and skip its
