Compilation is performed by the installed CODESYS Development System. The backend was checked with a valid program, an intentionally invalid program, and a corrected program. Their actual error counts were zero, two, and zero. All three processes returned exit code zero, so the wrapper cannot trust the exit code alone. It rebuilds the application and checks diagnostic severities, the submitted source hash, a unique request identifier, and evidence that the function block was compiled.
