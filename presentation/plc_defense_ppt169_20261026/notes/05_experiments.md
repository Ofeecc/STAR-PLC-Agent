The baseline is the unmodified smolagents Tool Calling Agent. Its normal agent loop selects the shared compiler tool. Our harness controls generation and repair explicitly. Both use the same DeepSeek route and Kimi route, the same tasks, the same three-build limit, and the same request settings. Codex was initially preferred, but its local tool policy prevented the required execution, so the baseline was changed before the full campaign. The baseline can make an extra model request to produce its final answer. That difference is disclosed.
