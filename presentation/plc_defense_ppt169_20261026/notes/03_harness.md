The harness first extracts the interface and behavioral constraints. It then asks the model for structured source, inserts that source into an isolated CODESYS project, and compiles it. If the compiler reports errors, the harness sends the current code and focused diagnostics back for repair. There are at most two repairs after the initial attempt. Every candidate and response is retained. Compilation success ends generation, while functional testing remains a separate stage. This control loop makes the system more than a single prompt.
