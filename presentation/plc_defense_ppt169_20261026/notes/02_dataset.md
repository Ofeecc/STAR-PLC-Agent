The dataset includes all twenty official questions and twelve independently constructed questions. Each task has a typed interface, initial state, priorities, temporal specifications, and fixed tests. Together they contain two hundred and seven LTL properties and eighty one test cases. Inputs are sampled before an invocation, and outputs are observed after that same invocation. For the guarded motor, a stop request must clear the run output in the current scan. This explicit convention avoids confusing pre-scan state with end-of-scan output.
