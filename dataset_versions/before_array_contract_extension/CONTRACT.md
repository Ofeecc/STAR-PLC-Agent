# Dataset contract version 1

Each UTF-8 task JSON has `schema_version: 1`, `id` (PUB001..PUB020 or SELF001..), `kind` (`public` or `self_built`), `title`, `difficulty` (`easy`, `medium`, `hard`), `provenance` (object with `source_type`, `source_file`, `source_index`, `adaptation`, `rationale`, `review`), `requirements` (full English text), `scenario`, `interface` (list of objects with `direction` INPUT/OUTPUT/IN_OUT, `name`, `type`, `description`), `initial_conditions` (object), `scan_semantics` (string), `safety_priority` (list), `assumptions` (list), `ltl` (list of `id`, `formula`, `explanation`), `atomic_propositions` (object defining every abbreviation), `tests` (list of `id`, `purpose`, `steps`, optional `notes`). Each step has complete `inputs` and partial `expected` output mappings; omitted expected outputs are unconstrained. Each test resets the FB instance. Record TIME/LTIME values as IEC literals such as T#100ms. Use `dt_ms` per step for physical elapsed-time requirements. Composite data are JSON lists/objects. No test outputs are actual PLC execution results.

Default scan convention: state s[k] contains sampled input I[k], pre-scan retained state q[k], and end-of-scan output O[k]; q[k+1] is updated state. Same-scan safety uses G(stop -> !run); next-state retention uses X. The initial instance is reset before step 0; step 0 itself executes normally. Explicit task-specific timing assumptions override this default and must be recorded. Finite tests do not prove unbounded LTL liveness.

Public source text must be preserved verbatim in `requirements`, with any interpretation separated into `assumptions`. Self-built tasks must be independently constructed and include a transparent synthesis/review record. Task tests and Python oracles are expected values, never CODESYS execution evidence.
