# 规约V2修订说明（2026-11-06）

当前正式工作目录dataset已逐题更新32题。公共题requirements原文均保持一致；旧题库已归档到dataset_versions/v1_before_20261106，旧结果只能对应旧题库。

本版244条性质（含32条完整行为数据谓词）、87组测试、595拍。新增6组漏检反例回归；12道自建题的预期值扩展为每拍全部输出。38项离线测试通过；六条已知错误轨迹均被新增期望值拒绝。这不代表执行了CODESYS或完成LTL模型检查。

## 修订的精度与剩余工作

12道自建题附有确定初值及完整Python状态转移定义，作为独立逐拍参考关系。公共20题补入逐题行为契约及明确的漏洞修复，但CompleteBehaviorV2仍是解释型数据谓词，其文字定义尚需展开为可执行监控器。不能将这些条目计作已经通过形式验证的性质。

PUB010继续采用原测试的>=5秒触发口径，明确标为评测解释；冷却第一个>=3秒观测拍必须解除。PUB007固定为start电平重选。PUB004/005的DebounceTime在一个用例内固定为正值。PUB015/019模式变化当拍清状态并抑制动作，第一调用正常执行。所有解释须同样提供给两个Agent。

新增字段specification_contract已经纳入Agent需求分析，并随完整题目JSON提供。后续要完成公共题监控器、更多边界用例及真实PLC验收。旧build_public/build_self_dataset脚本仍生成旧格式；不要直接重建覆盖当前V2，应先迁移构建器或重新应用版本化修订脚本。
